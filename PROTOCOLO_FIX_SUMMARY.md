### 1. INCONSISTÊNCIA DE SCHEMA ✅ CORRIGIDO
**Problema:** Frontend enviava campos incompatíveis com DB
- ❌ Enviava `id: uuid` mas DB esperava `bigint` (auto-identity)
- ❌ Enviava `id_cliente` mas coluna é `cliente_id`
- ❌ Enviava `id_proprietario` mas coluna é `admin_id`
- ❌ Campos inexistentes: `titulo`, `descrição`, `url_img_protocolo`

**Solução:** Migração SQL removeu conflitos e ajustou frontend
- ✅ `id` agora auto-gerado como `bigint IDENTITY`
- ✅ Frontend envia `cliente_id` (coluna correta)
- ✅ Frontend envia `admin_id` (coluna correta)
- ✅ Removidas colunas inúteis

**Arquivo:** `supabase/migrations/20260106_fix_protocolos_schema_rls_auditoria.sql`

---

### 2. POLÍTICA RLS PERMISSIVA ✅ CORRIGIDO
**Problema:** Política `USING (true)` permitia qualquer usuário ler todos os protocolos
```sql
-- ❌ ANTES: Vazamento de dados
CREATE POLICY "Public read access for specific protocol"
USING (true);  -- Sempre verdadeiro!
```

**Solução:** Política restrictiva alinhada ao padrão do sistema
```sql
-- ✅ DEPOIS: Seguro
CREATE POLICY "protocolos_admin_full_access"
USING (
  admin_id = auth.uid()
  OR admin_id IN (
    SELECT admin_usuarios.admin_id FROM admin_usuarios 
    WHERE admin_usuarios.id = auth.uid()
  )
);
```

**Resultado:** 
- ✅ Admin vê seus próprios protocolos
- ✅ Funcionários do admin veem protocolos do admin (via lookup)
- ✅ Outros admins são bloqueados (RLS nega)

---

### 3. AUSÊNCIA DE AUDITORIA ✅ CORRIGIDO
**Problema:** Sem campo para registrar quem criou o protocolo

**Solução:** Coluna `criado_por uuid DEFAULT auth.uid()`
```sql
ALTER TABLE public.protocolos
ADD COLUMN IF NOT EXISTS criado_por uuid NOT NULL DEFAULT auth.uid();

CREATE INDEX IF NOT EXISTS idx_protocolos_criado_por 
ON public.protocolos(criado_por);
```

**Resultado:** 
- ✅ Cada protocolo registra quem criou
- ✅ Imutável após criação (não é atualizado)
- ✅ Preenchido automaticamente via DEFAULT auth.uid()
- ✅ Índice para queries rápidas

## SCHEMA FINAL (CORRETO)

```sql
CREATE TABLE public.protocolos (
  id bigint PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  created_at timestamp with time zone DEFAULT now(),
  cliente_id bigint FOREIGN KEY -> tbl_clientes(id),
  admin_id uuid NOT NULL,                    -- ✅ Dono do protocolo
  numero_protocolo text,
  status text DEFAULT 'Impresso',
  img_protocolo text,                        -- ✅ URL da imagem
  nome_resp_recebimento text,
  data_recebimento timestamp with time zone,
  anexos jsonb,                              -- ✅ Array de URLs
  criado_por uuid NOT NULL DEFAULT auth.uid(), -- ✅ Auditoria
  CONSTRAINT protocolos_cliente_id_fkey FOREIGN KEY (cliente_id)
    REFERENCES public.tbl_clientes(id) ON DELETE SET NULL
);

ALTER TABLE public.protocolos ENABLE ROW LEVEL SECURITY;
```

## POLÍTICA RLS FINAL

```sql
CREATE POLICY "protocolos_admin_full_access" ON public.protocolos
AS PERMISSIVE FOR ALL TO authenticated
USING (
  admin_id = auth.uid()
  OR admin_id IN (
    SELECT admin_usuarios.admin_id
    FROM admin_usuarios
    WHERE admin_usuarios.id = auth.uid()
  )
)
WITH CHECK (
  admin_id = auth.uid()
  OR admin_id IN (
    SELECT admin_usuarios.admin_id
    FROM admin_usuarios
    WHERE admin_usuarios.id = auth.uid()
  )
);
```
